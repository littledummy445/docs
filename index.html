AppsOnline — Complete User Guide & Support Manual

Welcome to the official documentation manual for AppsOnline (appsonline.dpdns.org). This guide details our platform capabilities, storage configurations, and common technical fixes to ensure a smooth cloud streaming experience.

1. Getting Started with the Web Workspace

AppsOnline streams isolated operating system environments straight to your browser using advanced canvas compression protocols. To get optimal performance, please follow these core environment guidelines:

  • Recommended Browsers: For the lowest possible input delay, we recommend using Google Chrome, Brave, or Mozilla Firefox. Ensure your browser is fully updated to the latest stable release.

  • Input Control Integration: Your mouse and keyboard inputs are tracked natively.

  • To trigger a standard desktop right-click inside a container, simply use your regular physical mouse right-click.

  • If you are accessing the platform on a touchscreen mobile device, long-press on the element to open context menus.

2. Managing Your Persistent File Storage

By default, anonymous public sessions operate on a strict zero-persistence framework—all files are securely destroyed on tab close. To keep your work saved across multiple sessions, you must utilize our persistent storage layer:

  • Sign In: Click the Sign In handle on the main menu dashboard and authenticate safely via our GitHub OAuth / Cloudflare Access secure gateway.

  • Locate the Cloud Folder: Once your workspace initializes, open the system file explorer inside your Linux or Windows container.

  • The Target Directory: Look for the designated folder path labeled cloud-storage/. This folder links directly to a secure, isolated Amazon S3 storage bucket assigned to your developer token.

  • Saving Work: Any code repositories, text documents, or graphics configurations you save directly inside this specific directory will persist safely. When you log back in during a future session, your files will remount automatically.

3. Advanced Troubleshooting and Connection Fixes

🛑 Error: "ERR_CONNECTION_REFUSED" or Page Loading Loops

If the main launcher interface fails to load on your residential network (such as Frontier Home Fiber) but opens instantly on cellular data, your router's security protocols are blocking the stream.

  • The Fix: Open your router's administration interface (e.g., your Amazon Eero mobile app) and temporarily turn off "Advanced Security Script Filters" or "Ad-Blocking Toggles" that might flag public custom dynamic subdomains (*.dpdns.org).

  • Flush Local Cache: Open your computer terminal and execute ipconfig /flushdns to clear old network records.

⏳ Stream Freezes or Stutters

Because AppsOnline delivers real-time high-fidelity video streams, minor packet drops on your Wi-Fi will cause temporary interface stutters.

  • The Fix: Click the hidden streaming sidebar arrow on the left-hand margin of your container screen. Under Streaming Settings, drop your visual quality profile from "High Definition" down to "Medium" or "Automatic". This switches the canvas compression to compress the data faster, dropping latency instantly over slower connections.
